How this is calculated

Target DEF = base DEF × (1 + max general DEF skill + optional guild DEF skill + enabled DEF lead + DEF relic main %) + build +DEF. A DEF conversion exclusive effect then multiplies that total by 1 + (source stat ÷ “per N”) × gain %. Sonia must reach at least target DEF ÷ 0.6. Her required +ATK on build accounts for base ATK, general and optional guild ATK skills, enabled lead, ATK relic main %, and any ATK conversion exclusive effect.

The old glory buildings and guild flags became separate Summoner’s Tower skills. General DEF, ATK and Wind ATK skills apply in guild content too; the guild option adds guild-specific DEF and ATK skills. The relic main stat is 3% at +0, gains 1% per level through +14, and is 20% at +15. Exclusive conversion values vary by relic; enter the values printed in game. This estimates the threshold before other in-battle effects and game rounding.
