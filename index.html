How this is calculated

Target DEF = base DEF × (1 + DEF tower + enabled DEF lead) + build +DEF. Sonia must reach at least target DEF ÷ 0.6. Her required +ATK on build subtracts her 867 base ATK and base-stat bonuses from the ATK and Wind towers and enabled ATK lead.

Leader percentages are editable because the leader can be another unit. Tower fields start at max values. This estimates the stat threshold before in-battle buffs, debuffs, passives, or rounding by the game.
